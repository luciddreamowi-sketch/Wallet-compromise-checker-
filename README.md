# Wallet-compromise-checker-

A modern Web3 security tool that helps users quickly check if their crypto wallet may be compromised across multiple blockchain networks including Ethereum, Solana, Base, and Arbitrum.

🚀 Features

🔍 Wallet security analysis

🌐 Multi-chain support

Ethereum

Solana

Base

Arbitrum


⚠️ Detect suspicious wallet activity

🛡️ Smart contract interaction checks

📊 Clean and professional dashboard UI

⚡ Fast wallet scanning

📱 Responsive design for mobile & desktop

🌙 Dark mode Web3-inspired interface


🧠 How It Works

Users simply paste their wallet address into the checker, and the app analyzes wallet activity, permissions, suspicious transactions, and possible compromise indicators to help users stay safe in Web3.

🛠️ Tech Stack

Frontend: React / Next.js

Styling: Tailwind CSS

Blockchain APIs: Alchemy, Moralis, Helius

Wallet Integration: WalletConnect / RainbowKit

Hosting: Vercel


📦 Installation

Clone the repository:

git clone https://github.com/yourusername/wallet-compromise-checker.git

Navigate into the project folder:

cd wallet-compromise-checker

Install dependencies:

npm install

Run the development server:

npm run dev

🔑 Environment Variables

Create a .env.local file and add:

NEXT_PUBLIC_ALCHEMY_API_KEY=your_api_key
NEXT_PUBLIC_HELIUS_API_KEY=your_api_key
NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID=your_project_id
